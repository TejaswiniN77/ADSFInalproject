About | TNEB Electricity Prediction

TNEB Electricity Usage and Bill Prediction is a web-based machine learning project designed to estimate household electricity consumption and electricity bills using environmental conditions and household appliance usage data. The application combines data science and web development to provide a simple and accessible prediction system.

1. Project Overview

Electricity is an essential part of everyday life. Households depend on electrical appliances such as fans, refrigerators, washing machines, lights, and other equipment. Electricity consumption can change according to weather conditions, the number of people in a home, appliance operating hours, and previous consumption.

Understanding these factors can help users become more aware of their electricity usage and plan their monthly expenses. However, estimating future consumption manually can be difficult because several factors influence energy demand.

Our project uses machine learning models to analyse household and environmental information and generate predictions for electricity consumption and bill amounts. Users enter their details through a website and receive the predicted results on a separate results page.

2. Project Abstract

The main purpose of this project is to demonstrate how machine learning can be applied to household electricity consumption analysis. The system accepts input data such as temperature, humidity, rainfall, fan usage, washing machine usage, and previous-month electricity consumption.

The submitted information is processed using Python and Pandas. The trained machine learning models then generate an estimated electricity usage value in kilowatt-hours (kWh) and an estimated bill amount in Indian rupees.

FastAPI connects the prediction logic to the web interface, while HTML and CSS provide the pages through which users enter information and view results. The project illustrates the practical integration of data processing, machine learning, and web application development.

3. Problem Statement

Household electricity consumption varies from month to month. Changes in temperature, weather, appliance usage, household size, and daily routines can affect the amount of electricity consumed.

Without an estimation tool, users may find it difficult to understand how their usage patterns could influence future consumption and expenses. The objective is to develop a web application that uses historical data and machine learning to estimate electricity usage and bills from the information supplied by the user.

4. Project Objectives

The main objectives of the project are:

  • To develop a web-based electricity prediction system.
  • To estimate household electricity consumption using a trained machine learning model.
  • To estimate electricity bills using a bill prediction model.
  • To examine the relationship between environmental conditions and electricity consumption.
  • To consider household appliance usage and previous consumption as prediction inputs.
  • To present prediction results through a clear and user-friendly interface.
  • To demonstrate the application of data science techniques to a real-world problem.

5. Existing System

In a traditional electricity billing process, consumption is recorded over a billing period and the bill is calculated using the applicable billing rules. Users generally learn their actual consumption and charges after the relevant readings have been processed.

Manual estimation may not fully account for changes in appliance operating hours, weather, or household habits. A prediction application can provide an additional way to estimate possible consumption before the next bill becomes available.

6. Proposed System

The proposed system integrates a web interface with trained machine learning models. Users provide the required household and environmental information through a prediction form. The backend receives the form data, validates the values, and prepares the input for the trained models.

The electricity usage model predicts consumption in kWh. The bill model estimates the corresponding bill amount. The application then displays both values on the results page and compares predicted usage with the previous month's usage.

This approach provides an easy way to explore electricity consumption estimates without requiring users to run machine learning code manually.

7. Working Process of the Project

The project follows a sequence of data preparation, model training, user input, prediction, and result presentation.

  1. Dataset preparation: Historical electricity consumption records and relevant environmental and household features are prepared for model training.
  2. Data preprocessing: The dataset is checked for suitable column names, data types, missing values, and inconsistent records.
  3. Model training: Machine learning algorithms learn patterns from the training data to predict the selected targets.
  4. Model saving: The trained models are saved as files so that the web application can load and reuse them.
  5. User input: Users enter environmental details, appliance usage, and previous electricity consumption.
  6. Prediction: FastAPI passes the validated information to the appropriate trained models.
  7. Result display: The website presents the estimated usage, bill, and comparison with previous consumption.

8. Input Parameters

The prediction form uses the following information to generate an estimate:

  • Temperature: The environmental temperature in degrees Celsius. Temperature may influence cooling appliance usage.
  • Humidity: The relative humidity percentage, which describes the amount of moisture in the air.
  • Rainfall: The recorded rainfall in millimetres, representing one of the environmental features in the model.
  • Fan Usage: The number of hours the fan operates per day, according to the form's input definition.
  • Washing Machine Usage: The appliance operating hours specified by the user and defined by the dataset.
  • Previous Month Usage: The previous month's electricity consumption measured in kilowatt-hours.

The model can only use features that match its training configuration. Additional factors may influence actual household electricity consumption but are not necessarily represented in the current form.

9. Technologies Used

  • Python: Used to implement the backend and prediction logic.
  • FastAPI: Handles HTTP requests, form submissions, and communication between the website and the models.
  • Pandas: Organises input information into data structures required by the prediction pipeline.
  • Scikit-learn: Provides machine learning algorithms and tools for model training and prediction.
  • Joblib: Saves trained models and loads them into the application when required.
  • HTML: Defines the structure and content of each web page.
  • CSS: Provides the website's colours, layout, typography, visual effects, and responsive design.
  • Jinja2 Templates: Displays dynamic content, including prediction results and validation messages.
  • Uvicorn: Runs the FastAPI application server.

10. Main Features

  • A home page describing the purpose of the application.
  • A prediction form for entering household and environmental data.
  • Machine-learning-based electricity usage estimation.
  • Estimated bill generation using a trained bill model.
  • Input validation to reduce invalid values.
  • A results page displaying the prediction output.
  • A comparison between predicted usage and previous usage.
  • An About page explaining the project and its technologies.
  • A responsive interface for different screen sizes.

11. Benefits and Applications

This project demonstrates how data-driven techniques can support energy awareness. The predicted values may help users understand possible consumption patterns and plan their household expenses.

The same general approach can be explored in smart home applications, household energy monitoring, electricity consumption research, and energy analytics. These applications would require suitable data, appropriate validation, and reliable prediction models.

12. Future Enhancements

  • Expand the dataset with more representative household records.
  • Evaluate model accuracy using suitable validation methods.
  • Add charts to visualise monthly consumption trends.
  • Support more household appliances and relevant input features.
  • Introduce user accounts and saved prediction history.
  • Integrate smart meter data where available.
  • Compare different machine learning algorithms.
  • Use verified, current tariff rules to improve bill estimation.

13. Limitations

Prediction quality depends on the accuracy, size, and representativeness of the training dataset. A small dataset may not capture the full variety of household consumption patterns, and the model may not generalise well to every household.

The estimated bill is a model-generated prediction, not an official TNEB calculation. Actual electricity charges can depend on the applicable tariff, billing period, consumption category, subsidies, and other billing rules.

14. Conclusion

The TNEB Electricity Usage and Bill Prediction project demonstrates the integration of machine learning and web development to address a practical household energy estimation problem. It combines data preparation, trained prediction models, backend request handling, and a user-friendly interface.

By allowing users to submit household and environmental information and view estimated results, the application provides a foundation for exploring electricity usage patterns. Further improvements to the dataset, model evaluation, and tariff calculations can help make the system more reliable and useful.
